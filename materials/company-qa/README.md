# 産学連携プロジェクト　企業への質問リスト

カーディーラーとの産学連携プロジェクトで、企業担当者との質疑応答のときに学生が使う質問リストです。テーマは「2050年に向けた新店舗設計」です。

- 質問の例を A〜H の8つの観点で32問あげ、それぞれに「ねらい」（答えが提案のどこに役立つか）を付けた
  - A いまの店舗と課題を知る／B 2050年のお客様とクルマ／C 店舗の役割と機能／D 空間とデザイン／
    E テクノロジーとデジタル／F 環境と地域社会／G 店舗で働く人／H 提案に向けて
- 1ページ目に、リストの使い方、よい質問にするコツ、企業の情報の取り扱いの注意
- 最後のページに、質問と回答のメモ欄

| ファイル | 内容 |
|---|---|
| `company-qa.pdf` | 印刷・PDF書き込み用（A4、5ページ） |
| `company-qa.tex` | PDF の原稿（LuaLaTeX）。デザインは各回ワークシート（`../worksheets/preamble.tex`）と共通 |
| `Makefile` | ビルド（`make`） |
