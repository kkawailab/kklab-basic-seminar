# 産学連携プロジェクト　グループ活動記録シート

後半の産学連携プロジェクト（第6〜13回、5人程度のグループ）で、受講生が**個人で**記入する記録シートです。グループで話し合うたびに、次の4つを残します。

1. **出席**：自分の出欠と、メンバーの出欠（○△×）。欠席・遅刻した回は、事前の連絡の有無、共有してもらった内容、追いつくためにしたこと
2. **ディスカッションの成果**：今日の目的、決まったこと・できあがったもの、持ち越し、意見が分かれた点の決め方
3. **自分の役割**：担当した役割（チェック）、実際にやったこと、役割を果たせた度合い（1〜5）と理由
4. **気づき**：グループの進め方でうまくいったこと・改善したいこと、自分自身について気づいたこと

ほかに、次回までの分担（やること・担当・期限）を毎回書きます。

| ファイル | 内容 |
|---|---|
| `group-log.pdf` | 印刷・PDF書き込み用（A4、12ページ） |
| `group-log.docx` | Word 版（Word に直接入力する用、12ページ）。内容は PDF 版と同じ |
| `group-log.md` | Markdown 版（テキストエディタや Teams などで記入する用）。内容は PDF 版と同じ |
| `group-log.tex` | PDF の原稿（LuaLaTeX） |
| `build-docx.py` | Word 版を作るスクリプト（python-docx。部品は `../worksheets/tex2docx.py` と共通） |
| `Makefile` | ビルド |

## ページ構成（PDF・Word 共通）

| ページ | 内容 | 記入するとき |
|---|---|---|
| 1 | 使い方、名簿（①〜⑥）、グループで決めた約束（欠席の連絡、欠席者への共有、授業外の作業、意見が分かれたときの決め方） | 第6回（グループ編成時） |
| 2 | 出席と役割の記録（第6〜12回の一覧） | 毎回、記入後に1行で転記 |
| 3〜9 | 毎回の記録（第6〜12回、1回1ページ） | 各回の授業の最後の5分 |
| 10・11 | 予備（授業外の集まりや、日程が変わった回の用） | 必要なとき |
| 12 | プロジェクト全体の振り返り（出席の集計、役割の振り返り、気づき、メンバーの良かった行動） | 第13回 |

メンバーは1ページの名簿の番号（①〜⑥）で書くので、毎回名前を書き直す必要はありません。

## 運用のヒント（教員用）

- 欠席が続くメンバーがいるグループは、2ページの一覧と各回の「欠席者への共有」「次回までの分担」を見ると、共有や分担がどこで途切れているかが分かります。
- メンバーの出欠の記録は、責めるためではなく、欠席者への共有と分担の見直しに使うよう、使い方に明記しています。
- 第13回のワークシート（`../worksheets/sessions/13.tex`）の振り返りと合わせて使えます。

## 作り方

LuaLaTeX（TeX Live の jlreq、tcolorbox、tabularray）で組みます。色や記入欄の部品は各回ワークシートと共通で、`../worksheets/preamble.tex` を読み込んでいます。

Word 版は python-docx で作ります（入っていなければ `uv run --with python-docx` で一時的に使います）。

```sh
cd materials/group-log
make            # group-log.pdf と group-log.docx を作る
make pdf        # PDF 版だけ
make word       # Word 版だけ
make clean      # build/ を消す
```

中間ファイルは `build/` に入ります（Git には含めません）。

日程や題目を変えるときは、`group-log.tex` の `\logpage{回}{日付}{題目}` の行と、2ページの一覧の日付を直します。Word 版は `build-docx.py` の `SESSIONS` と一覧の日付を、Markdown 版（`group-log.md`）は手で同じ箇所を直してください。各回のページは1ページに収まるよう記入欄の高さを詰めてあるので、欄を足したときは `make` 後にページ数（12）が変わっていないか確認してください。
