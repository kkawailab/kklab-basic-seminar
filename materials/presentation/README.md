# 産学連携プロジェクト　提案発表のスライドテンプレート（5分）

第12回「最終プレゼン発表会」で使う、発表時間5分の PowerPoint テンプレートと、その作例です。話の組み立て方の違う5つの型があります。

## テンプレート

| ファイル | 型 | 流れ（発表のスライド） | 向いている場面 |
|---|---|---|---|
| `presentation-template-5min-basic.pptx` | 基本型 | 課題 → 顧客 → コンセプト → 空間 → 体験 → 効果・実現の道筋 → AI活用 → まとめ | 第11回のワークシートの流れそのまま。初めての提案発表 |
| `presentation-template-5min-situation.pptx` | 場面起点型 | 場面 → 本当にしたいこと → いまの選択肢 → 提案 → 空間と体験 → 効果・実現の道筋 → AI活用 → まとめ | 顧客の理解の深さで勝負したいとき |
| `presentation-template-5min-story.pptx` | 物語型 | 主人公 → ある日 → なぜ起きるのか → もしも → 新しい一日 → 物語を現実にする → AI活用 → 結び | 聞き手に場面を思い描いてもらいたいとき |
| `presentation-template-5min-conclusion.pptx` | 結論先行型 | 結論 → 根拠1 顧客 → 根拠2 空間 → 根拠3 体験 → 効果と進め方 → AI活用 → まとめ | 判断する立場の人に、短い時間で伝えるとき |
| `presentation-template-5min-compare.pptx` | 比較型 | 課題と判断の基準 → 顧客 → 検討した3つの案 → 選んだ案 → 空間と体験 → 効果・実現の道筋 → AI活用 → まとめ | 複数の案から選んだ理由を示したいとき |

どの型も、表紙を含めて発表のスライドは8〜9枚で、目安の秒数の合計が5分に収まるようにしてあります（10〜20秒の予備つき）。発表のスライドの後ろに、質疑用の「参考・出典」と「補足」が1枚ずつ付きます。

- **場面起点型**は、ジョブ理論（Jobs to Be Done）の考え方をもとにしています。顧客を属性ではなく「置かれた状況」で捉え、その状況で片づけたいこと（実用・気持ち・周りとの関係の3つの面）、いま代わりに選んでいるものとその不足、新しい方法に踏み出せない理由（不安と慣れ）を順に示してから提案します。スライド、ノート、レイアウト名には「ジョブ理論」という言葉を出していません。
- **物語型**は、ナラティブ（物語）の形式です。一人の主人公のつまずきから始め、原因、「もしも」の提案、新しい一日の順に語ります。空間と動線の説明は「新しい一日」の3つの場面に織り込みます。

### 使い方（受講生向けの説明は、各ファイルの最初のスライドにある）

- 最初のスライド「このテンプレートの使い方」は**非表示スライド**で、スライドショーには出ない。型の流れ、入力のしかた、時間配分の目安を載せている。提出の前に削除する
- 入力枠は PowerPoint のプレースホルダー。灰色の案内文をクリックして置き換える。入力しなかった枠は、スライドショーにも印刷にも出ない。文字が枠に収まらないときは自動で縮小される
- 図の枠は、中央のアイコンから画像を入れる。枠の形（角丸、円）に合わせて切り抜かれる
- 各スライドの**ノート**に、目安の秒数、原稿の字数（1秒5字）、話すこと、書き方、評価の観点を書いてある
- ［ホーム］→［新しいスライド］から同じレイアウトを追加できる。色とフォントはテーマで指定してあるので、［デザイン］→［バリエーション］から一括で変えられる

## 作例（`examples/`）

テーマ「2050年のカーディーラーの新店舗」で、5つの型すべてに内容を入れた作例です。企業名、数値、調査はすべて架空で、表紙と出典のスライドにその旨を書いてあります。図（ゾーニング図、場面のイラスト）は `make_images.py` で描いたものです。

| ファイル | 顧客ターゲット | 提案 |
|---|---|---|
| `examples/presentation-example-family-<型>.pptx` | 若いファミリー層 | 「試乗するのは、家族の一週間。」車ではなく、家族の暮らしを先に試せる店。入口のまちかどパーク、車内を部屋として並べたキャビン・リビング、子どもの一人乗りを親が確かめる見守りラウンジ |
| `examples/presentation-example-senior-<型>.pptx` | 免許を返納し、自動運転車を求める高齢者層 | 「免許は返した。行き先は、返さない。」車を選ぶ店ではなく、行き先を取り戻す店。まちの地図に行きたい所を置く行き先の広場、のりおり練習デッキ、家族と画面でつなぐ茶の間ラウンジ |

`<型>` は `basic`・`situation`・`story`・`conclusion`・`compare` です。同じ提案を5つの型で組み立ててあるので、型による見せ方の違いを比べられます。

## 構成

| ファイル | 内容 |
|---|---|
| `build.js` | テンプレートと作例を組み立てる（pptxgenjs）。レイアウトの部品（`patterns()`）と、型ごとの章・案内文・ノート（`VARIANTS`） |
| `examples/family.js`・`examples/senior.js` | 作例の内容（入力枠の名前 → 入れる文字、図のファイル名） |
| `examples/make_images.py` | 作例の図を描く（Pillow）。`examples/images/<題材>/` に書き出す |
| `examples/images/` | 作例の図（表紙、人物、ゾーニング図、場面） |

## 作り方

```sh
cd materials/presentation
npm install pptxgenjs                  # 初回のみ
node build.js                          # テンプレート5つ
node build.js story                    # 型を指定（basic・situation・story・conclusion・compare）

pip install Pillow                     # 初回のみ。フォントは Noto Sans CJK JP（fonts-noto-cjk）
python3 examples/make_images.py        # 作例の図
node build.js --examples               # 作例（2題材 × 5つの型）
node build.js --examples senior story  # 題材と型を指定
```

- **案内文や章の名前を変える**：`build.js` の `VARIANTS` の `layouts`（章の名前、案内文）と `slides`（時間配分、ノート）を直す。目安の秒数の合計が300秒を超えるとエラーになる
- **型を増やす**：`VARIANTS` に項目を足す。レイアウトは `patterns()` の部品（`rowsStat`・`persona`・`sceneRows`・`copy3`・`imagePoints`・`flow4`・`effectPlan`・`cols4`・`statement`・`alternatives`・`storyboard3`・`compare3`）を組み合わせる
- **作例の題材を増やす**：`examples/<題材>.js` を作り（`family.js` を写して書き換える）、図を `examples/images/<題材>/` に置く。`content` のキーは、`build.js` の各スライドの `use` に対応する

`build.js` は、pptxgenjs が書き出した pptx を開き直して、プレースホルダー（余白、縦位置、自動縮小、図の枠）、テーマの色とフォント（日本語は Yu Gothic）、ノートの段落を書き直しています。

## 確認したこと・していないこと

- ファイルの構造の検証（OOXML のスキーマ、参照の整合）は、全ファイルで通っている
- 文字の収まりは、Noto Sans CJK JP で描画して確認した。**PowerPoint の実機での表示は未確認**。Yu Gothic は字幅がほぼ同じだが、英数字の幅と行の高さがわずかに違うので、配布の前に PowerPoint で一度開いて確かめること
