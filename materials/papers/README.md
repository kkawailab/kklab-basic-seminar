# 授業用の架空論文

第4回「文献講読と批判的思考」の AI 演習（AI 要約と原文の照合、反論への応答）で使う、授業用の架空の論文です。学術誌の体裁をまねていますが、著者・所属・掲載誌・調査・データ・引用文献はすべて架空で、各頁の脚注と第1頁の注記にその旨を明記しています。

| ファイル | 内容 |
|---|---|
| `paper-x.tex` / `paper-x.pdf` | 架空論文Ｘ「都市部の若年層における自動車購入前の情報探索と販売店訪問」（14頁） |
| `preamble.tex` | 論文の共通レイアウト（jlreq、1段組、表・図は本文中に固定） |
| `Makefile` | ビルド（`make` で `paper-*.tex` をすべて PDF にする） |

## 作り方

LuaLaTeX（TeX Live の jlreq、tabularray、pgfplots、caption、fancyhdr）で組みます。

```sh
cd materials/papers
make            # すべての論文
make paper-x.pdf
make clean      # build/ を消す
```

中間ファイルは `build/` に入ります（Git には含めません）。

## 架空論文Ｘの仕込み（教員用）

記入例・模範解答（`../worksheets/answers/04.tex`）が参照している頁と、論文の該当箇所の対応です。本文を書き換えたときは、この対応が崩れていないか確認してください（`\newpage` で区切りを固定しています）。

| 記入例の記述 | 論文の箇所 |
|---|---|
| 問い：オンライン情報探索の量と、訪問する店舗数・回数の関係（p.2） | 1.2 本研究の問い（RQ1〜RQ3） |
| 方法：都市部の20〜34歳への Web 調査。過去3年に車を購入した人に限定（p.4） | 3.1 調査の概要。購入に至らなかった人を含まないことを明記 |
| 主な結果：探索が多い人ほど訪問店舗数は少ないが、1回の商談時間は長い（p.8） | 4.4 重回帰分析（太字の一文）と表4 |
| 情報源別の集計がある。動画の利用が多い人で訪問店舗数が少ない（表3、p.7） | 4.3 情報源の種類別の分析、表3 |
| 関心度で分けた分析があるが、関心の測り方が1問だけ（p.9） | 4.5 関心度別の分析、表5。測定が1項目であることは 3.2(3) に書いてあるが、限界としては挙げていない |
| 限界：Web 調査の偏り、一時点で因果は言えない（p.12） | 6. 本研究の限界と今後の課題（第一・第二） |
| 論文が答えていないこと：買わなかった人、来店の目的、地方と都市の違い | 6. の第三・第四・第五 |
| 主張：来店は「比べる場」から「決める場」へ | 要旨、5.2、7. おわりに |

AI 要約で起きやすいずれ（問いを広げる、「購入者に限定」を落とす、結果を言い過ぎる、限界の節を見落とす）を学生が見つけられるよう、これらはすべて原文に明示してあります。

## 新しい論文を足すとき

`paper-y.tex` のように `paper-` で始まる名前で置き、冒頭で `\input{preamble}` したうえで `\paperlabel`、`\journalname`、`\journalvol`、`\runninghead` を `\renewcommand` してください。`make` が自動で拾います。
