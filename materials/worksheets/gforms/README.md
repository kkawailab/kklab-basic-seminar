# 各回ワークシートの Google フォーム版

各回のワークシートを Google フォームにするための資料です。Google フォームは外部から直接は作れないため、
Google Apps Script（FormApp）で15回分を一括生成するスクリプトを、`../tex2gforms.py` が
`../sessions/NN.tex` から生成しています（`make gforms`）。

| ファイル | 用途 |
|---|---|
| `build-forms.gs` | Apps Script。実行すると Drive のフォルダに15回分のフォームと回答スプレッドシートができる。定義を埋め込んであるので、これだけで動く |
| `build-forms-github.gs` | 同じ Apps Script の軽い版。定義を埋め込まず、実行時に GitHub（main）の `forms.json` を読む。Drive のフォルダにもこの版を置いてある |
| `forms.json` | フォームの定義（タイトル、説明、セクション、質問、種類） |

先生の Google Drive のフォルダ「基礎演習Ⅱ 2026年度後期 ワークシート（Google フォーム）」にも
`build-forms-github.gs` を置いてある（回答が集まる場所なので、URL はこのリポジトリには書かない）。

## 作り方（初回のみ、5分）

1. https://script.google.com を開き、「新しいプロジェクト」を作る
2. `build-forms.gs` の内容をコード欄に貼り付けて保存する。Drive のフォルダ
   「基礎演習Ⅱ 2026年度後期 ワークシート（Google フォーム）」にある `build-forms-github.gs` でもよい
   （こちらは短いが、リポジトリの `forms.json` が GitHub に push されている必要がある）
3. 関数の選択で `buildAllForms` を選び、「実行」を押す。初回は Drive とフォームへのアクセスを許可する
4. 実行ログに各フォームの「編集」URL と「回答」URL が出る。Drive のフォルダ
   「基礎演習Ⅱ 2026年度後期 ワークシート（Google フォーム）」にフォームと
   回答スプレッドシート「基礎演習Ⅱ 2026年度後期 ワークシート回答」（回答は回ごとのシート）ができる

同じ名前のフォームがフォルダにあれば飛ばすので、何度実行しても重複しません。作り直すときは
そのフォームを削除してから実行します。1回分だけ作るときは、関数の選択で `buildOne` を選ぶ代わりに、
コード欄の末尾に `function run03() { buildOne('03'); }` のような関数を足して実行します。

## できあがるフォーム

- タイトルと説明（回・日付・フェーズ・この回のねらい）
- ワークごとのセクション見出し。説明にプロンプト例と指示文が入る
- 記入欄は「段落」、1行の記入欄は「記述式」、チェック項目は「チェックボックス」
- 学籍番号・氏名は必須
- 送信後に自分の回答を編集できる設定（授業中に送って、宿題のあとで直せる）
- 回答はフォルダ内のスプレッドシートに回ごとのシートで集まる

## 実行後に Google フォームで行うこと

- **スケッチの質問**（第8回「平面のゾーニング」、第9回「改善前」「改善後」）は、FormApp では作れない
  「ファイルのアップロード」の代わりに段落で置いてあります。編集画面で質問の種類を「ファイルのアップロード」に
  変えてください（回答者が Google アカウントでログインする設定になります）
- **回答者の制限**：大学の Google Workspace で使うなら、設定の「回答者」で組織内に限定し、
  メールアドレスを収集すると学籍番号との照合が楽になります。個人の Google アカウントで作った場合は
  「ログインを必須にする」をオフのままにし、学籍番号と氏名の質問で本人を確認します
- フォームの「回答」URL を授業サイトの各回ページ（`_sessions/NN-*.md` の `materials:`）に載せます

## 紙の記入欄の読み替え

Microsoft Forms 版（`../forms/`）と同じ読み替えです。

| 紙の記入欄 | Google フォームの質問 |
|---|---|
| 1行の記入欄 | 記述式 |
| 記入欄・罫線 | 段落 |
| 左の列が項目名の表 | 項目ごとに段落。書く列が複数あるときは「次の順に書く：…」を説明に |
| 空欄だけの表（候補や文献を並べる表） | 表ごとに1つの段落。列名を「／」でつないだ質問名にし、1件1行で書いてもらう |
| チェック項目・「次回までに」・注意書きの□ | チェックボックス |
| 方眼のスケッチ欄 | ファイルのアップロード（実行後に種類を変える） |
| プロンプト例・指示文 | セクション見出しの説明（または直後の質問の説明） |
| ペルソナカード | ペルソナごとに1つの段落 |
| AI活用記録 | 「使用した場面」「主なプロンプト」「出力をどう扱ったか」「検証したこと」の4問 |

## 原稿を直したとき

`../sessions/NN.tex` を直したら `make gforms` で `build-forms.gs` を作り直し、Apps Script に貼り直して、
作り直したい回のフォームを削除してから実行します。すでに回答が集まっているフォームは、
削除せずに Google フォームの編集画面で直すほうが安全です。
