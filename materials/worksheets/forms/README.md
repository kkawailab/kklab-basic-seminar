# 各回ワークシートの Microsoft Forms 版

紙・PDF・Word 版のワークシート（`../sessions/NN.tex`）を、Microsoft Forms のフォームとして
作るための資料です。`../tex2forms.py` で原稿から自動生成しています（`make forms`）。

| ファイル | 用途 |
|---|---|
| `forms-NN.md` | 設計書。セクション、質問、質問の種類（長い回答・選択肢など）、サブタイトルに入れる説明文を、Forms で作る順に並べたもの |
| `forms-NN.docx` | Forms の「クイック インポート」に読み込ませる Word ファイル。質問の下書きを一気に作るためのもの |

Microsoft Forms にはフォームを外部から作る API がないため、フォームそのものはここには置けません。
次の手順で、教員の Microsoft 365 アカウントに作ります。

## 作り方

### 1. Word ファイルを取り込む

1. https://forms.office.com を開き、「クイック インポート」→「このデバイスからアップロード」を選ぶ
2. `forms-NN.docx` を選び、「フォーム」（クイズではない）として読み込む
3. 「確認を開始」で、取り込めなかった箇所の指摘を見ながら手直しする（次の項）

クイック インポートが取り込めるのは「タイトル」「番号つきの質問」「A. B. の選択肢」だけです。
そのため `forms-NN.docx` は次の体裁にしてあります。

- 表や見出しは使わず、質問を 1. 2. 3. の番号で並べてある
- 各ワーク（■の見出し）の最初の質問に【ワーク名】を付け、指示文やプロンプト例は質問文の末尾に ※ で添えてある
- チェック項目は A. B. の選択肢にしてある

日本語の読み込みは英語より精度が落ちると Microsoft が案内しています。質問の区切りが
おかしいときは、設計書（`forms-NN.md`）と見比べて直してください。

### 2. 取り込み後の手直し

Word からは質問文しか入らないので、`forms-NN.md` を見ながら次を整えます。

- **長い回答**：記入欄の質問はすべて「テキスト」の「長い回答」にする（取り込み直後は短い回答）
- **複数選択**：A. B. の選択肢の質問は「複数回答」をオンにする（取り込み直後は単一選択）
- **ファイルのアップロード**：スケッチ（方眼の記入欄）は「ファイルのアップロード」に種類を変える。
  Forms では質問の種類を後から変えられないため、質問を削除して作り直す
- **セクション**：設計書の「セクション」ごとに「セクションの追加」で区切り、
  質問文の【ワーク名】をセクション名に移す（任意。区切らなくても使える）
- **サブタイトル**：質問文の末尾の「※」以降と（ ）内の指示は、質問の「…」→「サブタイトル」に移すと見やすい（任意）
- **必須**：学籍番号と氏名を必須にする
- **設定**：「所属組織内のユーザーのみが回答可能」「名前を記録」「回答は1人1回」にする。
  Forms が氏名とメールアドレスを自動で記録するので、氏名の質問は削除してもよい

### 3. Word を使わずに作る場合

`forms-NN.md` の順に Forms で質問を追加しても同じものができます。
Forms の Copilot（「Copilot で作成」）に `forms-NN.md` の内容を貼り付けて下書きを作らせる方法もありますが、
質問文が言い換えられることがあるので、できあがりを設計書と突き合わせてください。

## 記入欄の読み替え方

紙のワークシートの記入欄を、Forms の質問に次のように読み替えています。

| 紙の記入欄 | Forms の質問 |
|---|---|
| 1行の記入欄（`\fillin`） | テキスト（短い回答） |
| 記入欄・罫線（`\answerbox`、`\writelines`、`\twoboxes`） | テキスト（長い回答）。欄の見出しが質問文 |
| 左の列が項目名の表（`\hc{…}` の表や、見出し行つきで各行に項目名がある表） | 項目ごとにテキスト（長い回答）。書く列が複数あるときは「次の順に書く：…」をサブタイトルに |
| 空欄だけの表（候補や文献を並べて書く表） | 表ごとに1つのテキスト（長い回答）。列名を「／」でつないだ質問文にし、1件1行で書いてもらう |
| チェック項目（`checks`）、「次回までに」、注意書きの□ | 選択肢（複数選択可） |
| 方眼のスケッチ欄（`\gridbox`） | ファイルのアップロード（撮影した画像） |
| プロンプト例・指示文 | セクションの説明（または直後の質問のサブタイトル） |
| ペルソナカード | ペルソナごとに1つのテキスト（長い回答）。項目名の順に1行ずつ |
| AI活用記録 | 「使用した場面」「主なプロンプト」「出力をどう扱ったか」「検証したこと」の4問 |

学籍番号・氏名（グループ欄のある回はグループも）は、各フォームの最初の質問にしてあります。

## 原稿を直したとき

`../sessions/NN.tex` を直したら `make forms` で `forms-NN.md` と `forms-NN.docx` を作り直します。
すでに Forms に作ったフォームは自動では変わらないので、変わった質問だけを Forms 側で直してください。
新しいマクロを原稿で使うときは、`../tex2docx.py` と同じく `../tex2forms.py` にも対応を足します。
