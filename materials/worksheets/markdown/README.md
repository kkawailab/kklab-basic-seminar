# 各回ワークシートの Markdown 版

受講生がテキストエディタ（VS Code、Obsidian、メモ帳など）や Teams・Notion などで記入して
提出するための版です。内容は PDF 版・Word 版と同じで、`../sessions/NN.tex` から
`../tex2md.py` で自動生成しています（`make markdown`）。

## 記入のしかた（受講生向け）

- 「：」で終わる行の後ろに書く。長い答えは次の行から書いてよい
- チェック項目は `- [ ]` を `- [x]` にする
- 候補や文献を並べる欄は `1.` `2.` … の番号つきで、紙と同じ数だけ用意してある。足りなければ番号を増やし、余れば消してよい
- 点数や○×だけを書く表（第2回の採点、第12回の自己評価）は Markdown の表。`|` と `|` の間に書く
- スケッチの欄は、手描きしたものを撮影して画像を貼る（`![説明](ファイル名)`）か、画像ファイルを別に提出する
- AIの出力はそのまま写さず、要点を自分の言葉で書く

## 紙の記入欄の読み替え

| 紙の記入欄 | Markdown 版 |
|---|---|
| 1行の記入欄・記入欄・罫線 | `**見出し**：` の行。答えはその後ろか次の行から |
| 左の列が項目名の表 | `- **項目名**：` の箇条書き。書く列が複数ある項目は、列名の小項目に分ける |
| 空欄だけの表（候補や文献を並べる表） | `1. **1列目**：` と残りの列の小項目を、紙の行数ぶん並べる |
| 点数や○×だけの表 | Markdown の表 |
| チェック項目・「次回までに」・注意書きの□ | `- [ ]` のチェックリスト |
| プロンプト例 | 引用（`>`）。コピーして Copilot に貼って使う |
| 方眼のスケッチ欄 | 画像を貼る欄 |
| ペルソナカード | ペルソナごとの箇条書き |

## 原稿を直したとき

`../sessions/NN.tex` を直したら `make markdown` で作り直します。新しいマクロを原稿で使うときは、
`../tex2docx.py` と同じく `../tex2md.py` にも対応を足します。
