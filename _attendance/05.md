# 第5回の出席確認クイズ。
#   theme    : クイズのテーマ（一覧ページに表示される）
#   q        : 問題文
#   choices  : 選択肢（表示順はページを開くたびに入れ替わる）
#   answer   : 正解の選択肢の番号（0 が最初の選択肢）
#   explain  : 不正解のときに表示される解説
number: 5
theme: AIの得意・不得意と機械学習の基礎
questions:
- q: 大規模言語モデルが計算問題や論理パズルで間違えることがある理由として最も適切なものはどれでしょうか。
  choices:
  - 計算問題は学習データにまったく含まれないため
  - 計算機能があえて禁止されているため
  - 数字を入力できないため
  - 言語のパターンから「もっともらしい続き」を予測しているだけで、計算を厳密に実行しているわけではないため
  answer: 3
  explain: LLM は次の単語の予測にもとづいて答えるため、複雑な計算や厳密な論理では誤ることがあります。計算はツール（電卓や表計算）で確かめます。
- q: AIが「自信のある口調で誤った内容」を出したときの適切な対処はどれでしょうか。
  choices:
  - 断定の根拠を尋ね、一次資料で確認する
  - もう一度同じ質問をして、同じ答えなら信用する
  - 誤りは起こらないはずなので、そのまま使う
  - 口調が自信に満ちていれば正しいと判断する
  answer: 0
  explain: AIの口調の自信と内容の正しさは無関係です。「根拠は」「出典は」と尋ねたうえで、示された資料を自分で確認します。
- q: 「機械学習」の説明として最も適切なものはどれでしょうか。
  choices:
  - コンピュータが自分で電源を入れる仕組み
  - 機械を工場で組み立てる技術
  - データからパターンや規則性を学び、明示的に手順を書かなくても判断や予測ができるようにする手法
  - 人間がすべてのルールを一つずつプログラムに書き込む手法
  answer: 2
  explain: 機械学習は、大量のデータから統計的にパターンを学ぶ手法です。生成AIも、機械学習（特に深層学習）を用いて言語のパターンを学習しています。
- q: 「教師あり学習」の説明として適切なものはどれでしょうか。
  choices:
  - 正解ラベルの付いたデータを使って、入力と正解の対応を学習する
  - 学校の先生がAIに授業をする
  - 試行錯誤の結果に報酬を与えて行動を学ばせる
  - 正解のないデータからグループ分けを見つける
  answer: 0
  explain: 教師あり学習は、「この画像は猫」のように正解ラベルが付いたデータで学習する方法です。ラベルなしのデータから構造を見つけるのが教師なし学習、報酬で学ぶのが強化学習です。
- q: AIが示した数値の出典を確認できなかった場合、この授業での扱いとして適切なものはどれでしょうか。
  choices:
  - 「AIによると」と書けば使ってよい
  - 注に「未確認」と書いて使う
  - その数値は使わない
  - 小数点以下を切り捨てれば使ってよい
  answer: 2
  explain: 確認できない数値は使いません。数値や統計は、公的統計や論文などの一次資料にあたり、同じ数値であることを確かめてから使います。
