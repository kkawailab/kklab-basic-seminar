# 第14回の出席確認クイズ。
#   theme    : クイズのテーマ（一覧ページに表示される）
#   q        : 問題文
#   choices  : 選択肢（表示順はページを開くたびに入れ替わる）
#   answer   : 正解の選択肢の番号（0 が最初の選択肢）
#   explain  : 不正解のときに表示される解説
number: 14
theme: AIと仕事・キャリア
questions:
- q: AIが仕事に与える影響を考えるとき、多くの研究で用いられる見方はどれでしょうか。
  choices:
  - AIの影響は事務職だけに限られると考える
  - 職業全体ではなく、職業を構成する個々のタスク（作業）単位で、代替されるものと補完されるものを見る
  - AIが導入された職業は、すべての仕事がなくなると考える
  - AIは仕事に一切影響しないと考える
  answer: 1
  explain: ひとつの職業は多くのタスクからなり、AIが得意なタスクとそうでないタスクが混在します。どのタスクが変わり、どのタスクの価値が上がるかを考えることが、キャリアを考える基本になります。
- q: 「プロンプトエンジニアリング」の説明として適切なものはどれでしょうか。
  choices:
  - 望む出力を得るために、AIへの指示の書き方や構成を設計・改善する技術
  - AIに関する法律を作る仕事
  - AIの電源配線を行う技術
  - AIのハードウェアを設計する技術
  answer: 0
  explain: プロンプトエンジニアリングは、役割・目的・条件・出力形式などを工夫して、AIから質の高い出力を引き出す技術です。仕事で広く求められる基礎スキルになりつつあります。
- q: 就職活動でエントリーシートの作成に生成AIを使うときの注意として、最も適切なものはどれでしょうか。
  choices:
  - AIに丸投げして、そのまま提出する
  - AIを使ったことは面接で聞かれても否定する
  - 自分の経験と考えを自分で書き、AIは構成の整理や表現の推敲に使い、内容が事実であることを確認する
  - AIが作った経験談を自分のこととして書く
  answer: 2
  explain: エントリーシートは面接で深掘りされます。自分の経験にもとづいて書き、AIは整理や推敲に使うのが基本です。企業によってはAI利用の方針を示している場合もあるので確認します。
- q: 企業の「AIガバナンス」とは何を指すでしょうか。
  choices:
  - AIの利用を全面的に禁止すること
  - AIの利用ルール、責任体制、リスク管理の仕組みを整え、適切に運用すること
  - AIを社長に任命すること
  - AIの購入費用を管理すること
  answer: 1
  explain: AIガバナンスは、どのAIを、どの業務に、どんなルールと責任体制で使うかを組織として定め、運用・見直しを行うことです。就職先でAIを使うときも、その組織のルールに従います。
- q: 職場で生成AIを業務に使うときに、最初に確認すべきことはどれでしょうか。
  choices:
  - 職場のAI利用に関する規程やルール（使ってよいツール、入力してよい情報）
  - AIの画面の色
  - AIの開発企業の株価
  - AIの回答速度
  answer: 0
  explain: 多くの組織では、利用を認めるツールや、入力してはいけない情報（顧客情報、機密情報）を定めています。大学の規程を確認するのと同じように、職場でも規程を確認してから使います。
