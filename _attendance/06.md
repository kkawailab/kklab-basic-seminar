#   theme    : クイズのテーマ（一覧ページに表示される）
#   q        : 問題文
#   choices  : 選択肢（表示順はページを開くたびに入れ替わる）
#   answer   : 正解の選択肢の番号（0 が最初の選択肢）
#   explain  : 不正解のときに表示される解説
number: 6
theme: AIと個人情報・機密情報
questions:
- q: 企業から提供された非公開の資料やデータをAIに入力することについて、適切な行動はどれでしょうか。
  choices:
  - 要約するだけなら、そのまま入力してよい
  - 公開されていなくても、学生の演習なら問題ない
  - 入力しない。必要なら企業と教員に確認し、許可された範囲でのみ扱う
  - ファイル名を変えれば入力してよい
  answer: 2
  explain: 産学連携で提供される非公開情報は、契約と信頼にもとづいて共有されています。AIへの入力は情報漏えいにつながりうるため、許可なく入力してはいけません。
- q: 次のうち、個人情報にあたる可能性が最も高いものはどれでしょうか。
  choices:
  - 一般的な商品の平均価格
  - 都道府県ごとの人口
  - 氏名と住所、生年月日の組み合わせ
  - 公開されている企業の売上高
  answer: 2
  explain: 個人情報は、特定の個人を識別できる情報です。氏名・住所・生年月日などの組み合わせは典型例で、他人の個人情報をAIに入力してはいけません。
- q: 生成AIに入力した内容が、AIの学習に使われる可能性について正しい説明はどれでしょうか。
  choices:
  - サービスや契約によって異なるため、利用規約やデータの取り扱いを確認する必要がある
  - どのサービスでも、入力内容は必ず学習に使われる
  - どのサービスでも、入力内容が学習に使われることはない
  - 学習に使われるかどうかは利用者には確認できない
  answer: 0
  explain: 無料の個人向けサービスでは入力が学習に使われる設定になっていることがあり、組織向け契約では学習に使わないと定められていることが多いです。使う前に規約を確認します。
- q: マーケティングでいう「ペルソナ」とは何でしょうか。
  choices:
  - 商品の価格表
  - 企業のロゴやブランドカラー
  - ターゲットとなる顧客を、年齢・職業・価値観などを持つ具体的な人物像として描いたもの
  - 店舗の設計図
  answer: 2
  explain: ペルソナは、想定顧客を具体的な一人の人物として描いた設定です。AIと対話しながら作り込むことで、行動や動機を具体的に想像しやすくなります。
- q: 授業で大学提供の Copilot を使う利点として最も適切なものはどれでしょうか。
  choices:
  - 個人向けサービスより回答が常に正しい
  - 利用の記録を残さなくてよい
  - 入力した内容をクラス全員が見られる
  - 大学の組織アカウントで利用でき、データの取り扱いが大学の規程と契約のもとで管理されている
  answer: 3
  explain: 組織アカウントで使うAIは、データの取り扱いが大学の契約と規程にもとづいて管理されます。それでも、非公開情報や個人情報を入力してよいわけではなく、活用の記録も必要です。
